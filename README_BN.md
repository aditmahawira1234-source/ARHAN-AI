# ARHAN-AI (উন্নত সংস্করণ)

এই সংস্করণে:
- বাংলা চ্যাট ইন্টারফেস
- সার্ভারে কথোপকথনের ইতিহাস `data/history.json` ফাইলে সংরক্ষণ
- সার্ভার বন্ধ করে আবার চালু করলেও আগের চ্যাট দেখা
- OpenAI API key সার্ভারের `.env` ফাইলে রাখা—ব্রাউজারে প্রকাশ করা হয় না
- চ্যাট মুছে ফেলার বোতাম

## যা লাগবে
- Node.js 18 বা তার পরের সংস্করণ
- OpenAI API key এবং API ব্যবহারের অনুমতি/বিলিং

## চালানোর নিয়ম
1. ছয়টি ফাইল একই ফোল্ডারে রাখো।
2. `.env.example` কপি করে `.env` নামে রাখো।
3. `.env` ফাইলে নিজের API key বসাও।
4. টার্মিনালে ওই ফোল্ডারে গিয়ে চালাও:

   ```bash
   npm install
   npm start
   ```

5. ব্রাউজারে `http://localhost:3000` খোলো।

## স্মৃতি কীভাবে কাজ করে
পুরো কথোপকথন `data/history.json` ফাইলে জমা থাকে। AI-কে প্রতিটি উত্তরের সময় সর্বশেষ ৩০টি বার্তা পাঠানো হয়। তাই:
- পুরোনো সব বার্তা ফাইলে থাকলেও AI একবারে সব বার্তা পড়ে না।
- সব কথা আজীবন নিখুঁতভাবে মনে রাখার নিশ্চয়তা নেই।
- গুরুত্বপূর্ণ তথ্য আলাদা করে নিরাপদ জায়গায় লিখে রাখো।
- চ্যাট মুছলে সংরক্ষিত ইতিহাসও মুছে যাবে।

## নিরাপত্তা
- `.env` বা API key কাউকে দেবে না।
- `.env` GitHub-এ আপলোড করবে না।
- এই starter app-এ লগইন/ব্যবহারকারীভিত্তিক নিরাপত্তা নেই। পাবলিক ইন্টারনেটে চালানোর আগে authentication, HTTPS, rate limiting এবং database যোগ করতে হবে।
- `data/history.json`-এ ব্যক্তিগত তথ্য থাকতে পারে; ফাইলটি শেয়ার কোরো না।

## GitHub-এ আপলোড
`.env.example` আপলোড করা যায়; `.env` এবং `data/history.json` আপলোড কোরো না। `.gitignore` এগুলো বাদ রাখে।
